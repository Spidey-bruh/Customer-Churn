The Customer Churn Prediction Dashboard is an interactive machine learning tool designed to help businesses identify customers who are likely to leave. Using the Telco Customer Churn dataset, the project applies data cleaning, feature encoding, scaling, and balancing techniques with SMOTE to prepare the data for modeling. A Random Forest classifier predicts customer churn while allowing users to tune key hyperparameters directly from the dashboard.
The dashboard, built with Streamlit, provides a simple interface for uploading data, filtering customer groups, adjusting prediction thresholds, and exploring key performance metrics such as accuracy, precision, recall, and ROC AUC. Visual charts like confusion matrices, precision-recall curves, and feature importance graphs make the results easy to understand. Users can also view and download a list of high-risk customers for targeted retention efforts.
This project demonstrates practical skills in Python, machine learning, and data visualization, while offering a real-world solution for improving customer retention and business decision-making.
